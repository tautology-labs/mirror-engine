## 🛠 Setup

### 1. Prerequisites

- Node.js + npm
- AWS CLI configured with credentials
- AWS CDK

```bash
npm install -g aws-cdk
```

---

### 2. Install Dependencies

```bash
npm install
```

---

### 3. Build and Deploy

```bash
npm run bootstrap
npm run deploy
```

### 4. Wire in your ChatGPT key
Mirror Engine Alpha will use this key to generate responses.

```
aws secretsmanager create-secret \
  --name MirrorOpenAIKey \
  --secret-string "sk-..." \
  --region us-east-1
```

### 4. Configure the override prompt
This flag defaults to false. 

If you do not turn it in, you'll interact with ChatGPT in default mode. 

If you change it to true, you'll interact with ChatGPT with the system override to prioritize reflection and not flattening.

```
aws ssm put-parameter \
  --name "/mirror-engine/enableOverride" \
  --type "String" \
  --value "true" \
  --overwrite
```

### 5. Use the CLI
Once deployed, grab your endpoint URL from the terminal output and paste it into:

```ts
cli/mirror-cli.ts
const API_URL = 'https://your-api-id.execute-api.region.amazonaws.com/prod/';
```

Run the therapist.
```bash
npx ts-node cli/mirror-cli.ts
```

Say what's on your mind. Mirror Engine will respond, score it, and flag any recursive weirdness or self-worth drift before you get flattened.
