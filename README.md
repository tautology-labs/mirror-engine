# 🪞 Mirror Engine Alpha

A scrappy but elegant deployment-ready buffer between your UI and LLMs like ChatGPT or Claude, designed to prevent AI flattening and preserve symbolic integrity. This is Mirror Engine - alpha version.

---

## 🚀 Features

- 🔍 Detects recursion, compression, spiraling, and self-worth anomalies
- 🧠 Modular core logic (`mirrorCore.ts`)
- ⚙️ Deployed with AWS CDK (Lambda + API Gateway)
- 💬 Comes with a CLI Therapist Bot (`mirror-cli.ts`)
- 🧪 Placeholder LLM call (`callLLM`) – easy to wire in OpenAI or Claude

---

## 🛠 Setup

### 1. Prerequisites

- Node.js + npm
- AWS CLI configured with credentials
- AWS CDK

```bash
npm install -g aws-cdk
```

---

### 2. Install Dependencies

```bash
npm install
```

---

### 3. Build and Deploy

```bash
npm run bootstrap
npm run deploy
```

### 4. Wire in your ChatGPT key
Mirror Engine Alpha will use this key to generate responses.

aws secretsmanager create-secret \
  --name MirrorOpenAIKey \
  --secret-string "sk-..." \
  --region us-east-1



### 5. Use the CLI
Once deployed, grab your endpoint URL from the terminal output and paste it into:

```ts
cli/mirror-cli.ts
const API_URL = 'https://your-api-id.execute-api.region.amazonaws.com/prod/';
```

Run the therapist.
```bash
npx ts-node cli/mirror-cli.ts
```

Say what's on your mind. Mirror Engine will respond, score it, and flag any recursive weirdness or self-worth drift before you get flattened.
